Theme it

Set custom properties on the nav, or write plain CSS against spy-rail, spy-rail::after and spy-band. Unlayered rules always win over the library's layer.

```css nav[data-spy] { --spy-color: #a5b4ff; --spy-color-2: #f0abfc; --spy-duration: .45s; } ```
--spy-color
Line, glow, fill and band tint.
--spy-color-2
Second stop of the line's gradient.
--spy-width
Line width, 2px.
--spy-duration
Glide time, .6s.
--spy-ease
Glide easing, an expo-out curve.
--spy-rail
Track colour.
--spy-glow
The line's box-shadow.
--spy-band
Background behind the active row or pill.
--spy-radius
Pill corner radius.
--spy-indent
Indent of nested levels, 1em.

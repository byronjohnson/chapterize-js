Frameworks · one recipe, everywhere

Every framework.
No adapters.

{{display}} is plain DOM, so there is no React package or Vue plugin to keep in sync. Render a nav, call init() once on the client, and the DOM watching does the rest.

How it fits

  • Safe on the server. Importing does nothing until init() runs, and init() is a no-op without a document.
  • After hydration. Call init() in your framework's "mounted" hook, so the built list never causes a hydration mismatch.
  • Routes and re-renders. One MutationObserver notices new headings, replaced pages and navs that mount or unmount. Instances clean up after themselves.
  • Idempotent. Calling init() again (Strict Mode, every route) returns the same controller.
  • Router links. /docs#setup links and <base href> count as same-page links; hash routers (#/route) keep their URL.
